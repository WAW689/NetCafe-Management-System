# NetCafe Management System

## 项目简介

基于 Python + MySQL 开发的网吧管理系统，实现会员管理、上机管理、商品销售、充值管理和数据统计等功能。

## 技术栈

- Python
- MySQL
- SQL
- Tkinter
- Pandas

## 功能模块

- 管理员登录
- 会员管理
- 上机管理
- 商品销售
- 充值管理
- 数据统计与报表

## 数据库设计

数据库名称：

jerry_game

核心数据表：

- admin
- member
- computer
- internet_record
- product
- sales_order
- order_detail
- topup_record
